EXPLAINABLE BY DESIGN

Four agents. An evidence trail you can follow.

Each agent is a small JavaScript module with a single responsibility. The default decision uses transparent rules; optional Azure OpenAI adds an advisory explanation. The same evidence and payment policy remain visible in either mode.

The demo risk policy

Unknown vendor: +80 · New bank account: +60 · Domain mismatch: +35 · Amount outside range: +20 · Unusual urgency: +20.

Scores are capped at 100. LOW 0–19 MEDIUM 20–59 HIGH 60–100

These are demonstration weights, not fraud probabilities. A new bank alone requires verification; other deviations add context. Missing email text is explicitly marked as unassessed. No real payments are initiated, blocked, or released by this app.
